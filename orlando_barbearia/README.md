# 🪒 Barbearia Orlando

Site institucional profissional para a Barbearia Orlando - Tradição & Estilo

## 📋 Sobre o Projeto

Site moderno e responsivo desenvolvido para a Barbearia Orlando, combinando design vintage com funcionalidades modernas. O site apresenta informações sobre a barbearia, galeria de trabalhos, horários de funcionamento e sistema de agendamento.

## ✨ Características

- 🎨 Design moderno com toque vintage
- 📱 Totalmente responsivo (mobile-first)
- ⚡ Performance otimizada
- 🎯 SEO friendly
- ♿ Acessibilidade
- 📞 Sistema de agendamento por telefone/presencial

## 🚀 Tecnologias Utilizadas

- **HTML5** - Estrutura semântica
- **CSS3** - Estilização moderna com variáveis CSS
- **JavaScript (Vanilla)** - Interatividade e funcionalidades
- **Unsplash API** - Imagens de alta qualidade

## 🛠️ Instalação e Uso

### Pré-requisitos

- Navegador moderno (Chrome, Firefox, Safari, Edge)
- Servidor web local (opcional, para desenvolvimento)

### Instalação

1. Clone o repositório:
```bash
git clone https://github.com/DinisMiranda/orlando-barber.git
cd orlando-barber/orlando_barbearia
```

2. Abra o arquivo `index.html` no navegador ou use um servidor local:

```bash
# Com Python 3
python -m http.server 8000

# Com Node.js (http-server)
npx http-server

# Com PHP
php -S localhost:8000
```

3. Acesse `http://localhost:8000` no navegador

## 📝 Personalização

### Atualizar Informações de Contato

Edite os seguintes arquivos:

- **Telefone**: Procure por `(00) 0000-0000` e substitua
- **Email**: Procure por `contato@barbeariaorlando.com` e substitua
- **Endereço**: Procure por `Rua Exemplo, 123 - Centro` e substitua

### Atualizar Horários

Edite o arquivo `agendar.html` na seção de horários.

### Adicionar Imagens Próprias

Substitua as URLs do Unsplash pelas suas próprias imagens:

1. Coloque as imagens na pasta `assets/images/`
2. Atualize os caminhos no HTML

### Personalizar Cores

Edite as variáveis CSS no arquivo `styles.css`:

```css
:root {
    --color-primary: #E85A4F;        /* Cor principal */
    --color-text-primary: #1E2432;  /* Cor do texto principal */
    --color-background: #FCFBF9;    /* Cor de fundo */
    /* ... */
}
```

## 📱 Seções do Site

### Página Principal (`index.html`)

- **Hero Section**: Apresentação principal com call-to-action
- **Vídeo**: Seção para vídeo institucional
- **Sobre Nós**: Informações sobre a barbearia
- **Galeria**: Portfólio de trabalhos realizados
- **Nosso Espaço**: Fotos do ambiente da barbearia

### Página de Agendamento (`agendar.html`)

- **Métodos de Agendamento**: Telefone e presencial
- **Informações de Contato**: Telefone, email e endereço
- **Horários**: Horários de funcionamento
- **Localização**: Mapa interativo do Google Maps
