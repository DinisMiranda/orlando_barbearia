# Guia de Contribuição

Obrigado por considerar contribuir para o projeto da Barbearia Orlando! 🎉

## Como Contribuir

### Reportar Problemas

Se encontrar algum bug ou tiver sugestões de melhoria:

1. Verifique se o problema já não foi reportado nas [Issues](../../issues)
2. Crie uma nova issue com:
   - Descrição clara do problema
   - Passos para reproduzir (se aplicável)
   - Screenshots (se aplicável)
   - Navegador e versão utilizados

### Sugerir Melhorias

Sugestões são sempre bem-vindas! Abra uma issue descrevendo:
- A funcionalidade que gostaria de ver
- Por que seria útil
- Como você imagina que funcionaria

### Padrões de Código

- Use indentação consistente (2 espaços)
- Comente código complexo
- Mantenha nomes de variáveis descritivos
- Siga a estrutura de pastas existente

### Processo de Pull Request

1. Faça um fork do projeto
2. Crie uma branch para sua feature (`git checkout -b feature/MinhaFeature`)
3. Commit suas mudanças (`git commit -m 'Adiciona MinhaFeature'`)
4. Push para a branch (`git push origin feature/MinhaFeature`)
5. Abra um Pull Request

## Áreas que Precisam de Ajuda

- Tradução para outros idiomas
- Melhorias de acessibilidade
- Otimização de performance
- Testes
- Documentação

Obrigado por contribuir! 🙏
