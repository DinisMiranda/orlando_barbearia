# Política de Segurança

## Versões Suportadas

Atualmente suportamos as seguintes versões:

| Versão | Suportada          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reportando Vulnerabilidades

Se você descobrir uma vulnerabilidade de segurança, por favor:

1. **NÃO** abra uma issue pública
2. Envie um email para: contato@barbeariaorlando.com
3. Inclua detalhes sobre a vulnerabilidade
4. Aguarde nossa resposta antes de divulgar publicamente

Agradecemos sua ajuda em manter o projeto seguro! 🔒

## Boas Práticas de Segurança

- Sempre mantenha dependências atualizadas
- Use HTTPS em produção
- Valide e sanitize todas as entradas do usuário
- Implemente Content Security Policy (CSP)
- Use headers de segurança apropriados
